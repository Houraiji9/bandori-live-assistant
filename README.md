# 邦多利演出助手

Windows 64 位便携版。助手运行在电脑上，可连接 MuMu 模拟器；单曲模式也支持通过 ADB 连接安卓真机。

**[下载 Windows 首装整包](https://github.com/Houraiji9/bandori-live-assistant/releases/latest/download/bandori-friends-full-windows.zip)** · [版本记录与 SHA256](https://github.com/Houraiji9/bandori-live-assistant/releases) · **[Agent 环境适配与故障自查手册](AGENT自查手册.md)**

## 第一次使用

1. 将整包解压到自己可写的文件夹。双击根目录的 **启动邦多利.cmd**。
2. 推荐将模拟器分辨率设为 **1280×720（16:9 横屏，无黑边）**，在「设备」页连接模拟器或安卓真机并选择区服（国服 / 日服）。下次启动可自动连接已记住的模拟器。
3. 在「谱面」页选择歌曲和难度，首次使用可下载公开谱面。「演出控制」会记住上次的选择。微操方案在「微操方案」页管理，在「演出控制」勾选应用。

初次获取谱面、曲绘或 Bestdori 计算资源需要联网。下载的资料缓存在自己的「本地数据」目录。程序包不附个人账号、角色档案或演出记录。

## 更新与迁移

- **程序内更新**　打开「系统设置 → 程序更新」，检查并下载。校验通过后选「下次启动使用」。在当前演出结束后由你退出，从原来的根目录入口打开新版。
- **手动更新**　演出结束并退出后，将新版首装整包解压到原安装目录，保留根目录的「本地数据」。请直接覆盖解压，避免将新目录套在旧目录里面。
- **换电脑**　将整个安装目录一起复制，或先在新电脑解压首装包，再复制自己的「本地数据」。个人设置、微操方案和谱面缓存在该目录中。

## 环境不适配与 Agent 自查

如果在新电脑或不同模拟器环境下遇到**无法启动、找不到模拟器、ADB 断连、画面比例不适配、无法识别房间/曲目、打歌偏移/漏键或结算卡住**等问题，可直接将仓库中的 **[AGENT自查手册.md](AGENT自查手册.md)**（首装包根目录亦自带一份）交给本地 AI Agent 按步骤只读体检并输出诊断报告。

## 当前支持与验证范围

- **平台与客户端**：Windows 10/11 x64；支持国服 B 站官服（`com.bilibili.star.bili`）与日服官服（`jp.co.craftegg.band`），渠道服与其他外服包名暂未适配。
- **已实机验证**：国服挑战演出 / CP 演出、国服公开协力与车队（含新活动结算弹窗、少人/末段未到 SSS 跳车、赛前临时 AP 与自动补火）、单曲排练与微操方案。
- **待活动实机验收**：对邦与 5v5 的完整活动现场仍待对应活动开放后验收。
